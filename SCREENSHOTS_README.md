## User Roles Demonstrated

These screenshots show the **Admin** view with full access to all features. Different roles (Manager, Sales, Marketing, Support) will see filtered navigation based on their permissions.

## Technology Stack

- **Framework:** Next.js 15.5.6 with Turbopack
- **Database:** SQLite with Prisma ORM
- **Authentication:** NextAuth.js with bcrypt
- **UI:** Tailwind CSS v4 + shadcn/ui components
- **API:** tRPC for type-safe API routes
- **Language:** TypeScript
